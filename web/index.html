Getting started

      
Write a program in the editor and press Run, or pick one from
      Examples to watch it draw. To try a single command, type it in the
      ? box and press Enter. The turtle starts in the middle of the canvas, facing up.

      
For more room to draw, drag the line between the editor and the canvas, press
      Expand canvas, or use the full screen button under the canvas.

      
repeat 4 [forward 100 right 90]
to star :size
  repeat 5 [fd :size rt 144]
end
star 120

      
    

    

      
Keys

      

        
Ctrl+Enter or ⌘+Enter
Run the program

        
Esc
Stop a running program (it keeps your procedures and variables)

        
Enter in the ? box
Run one command; ↑ and ↓ bring back earlier ones

        
Tab in the editor
Indent; Shift+Tab outdents, and Esc then Tab moves on

      

      
A program that asks for input reads lines from the ? box (READWORD, READLIST)
      and keys pressed on the canvas (READCHAR, KEYP). Point at the canvas to see
      the turtle coordinates under the pointer.

About

      
This is the same Python engine as the terminal version, running in your browser through
      Pyodide, which is downloaded once (about 12 MB) and then cached.
      Your programs stay on your computer: the editor is saved in this browser, and a share link carries
      the program in the address itself.

      
To install it on your own computer, see the project page.
